Good to know

Page numbers make long documents navigable: readers can cite 'page 12', printers can check nothing is missing, and a dropped stack of pages can be put back in order. They are expected in reports, contracts, theses and manuals.

  • Start numbering after the cover page by setting the starting page — a title page usually stays unnumbered.
  • Bottom-centre is the safest position: visible on every print and never hidden by bindings.
  • Match the number size to the document text so the numbers look like they belong.

Frequently asked questions

Is my PDF uploaded to a server?

No. The numbers are drawn onto the pages entirely in your browser using the pdf-lib JavaScript library, so even confidential documents stay on your device.

What does "start numbering at" do?

It sets the number printed on the first page. With a start of 1 the first page is "Page 1 of Y". Start at 0 if page 1 is a cover that should show 0, or at any other number if this file continues a larger document. The "of Y" total always counts every page in the file plus the offset you chose.

Will the numbers cover my content?

Numbers are placed 20–24 pt from the page edge, inside the margin area of typical documents. If your pages have no margins, move the position or check the result — the original file is never changed, so you can simply try again.

Can I number a password-protected PDF?

Encrypted or password-protected PDFs cannot be read by the browser library. Remove the password in your PDF viewer first, then add numbers.
