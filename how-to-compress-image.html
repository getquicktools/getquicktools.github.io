Good to know

Big photos slow everything down: websites load slowly, email attachments bounce, and listing sites reject uploads. Compression removes data your eyes barely notice, so the same picture can weigh a tenth as much and still look the same on screen.

  • Start at a high quality setting (around 80) — most photos show no visible difference.
  • Compress the original, not an already-compressed copy: every re-save costs a little more quality.
  • For websites, resize first with the Resize Image tool, then compress — dimensions and weight both drop.

Frequently asked questions

Is my image uploaded anywhere?

No. Compression happens entirely in your browser with the HTML canvas, so your photo never leaves your device.

Why didn't my PNG get much smaller?

PNG is lossless — it keeps every pixel exactly, so it compresses less. If file size matters most, switch the output format to JPG or WebP.

What quality setting should I use?

0.75–0.85 usually cuts file size dramatically while staying visually sharp. Go lower (0.4–0.6) for thumbnails or when size matters more than detail.

Does compressing change the image dimensions?

No — width and height stay exactly the same. Only the file encoding (and therefore the file size) changes.
