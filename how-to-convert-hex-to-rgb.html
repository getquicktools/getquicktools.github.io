Good to know

The same colour wears different uniforms: #FF5733 in a stylesheet (HEX), rgb(255, 87, 51) in other code (RGB), hsl(11, 100%, 60%) when designers think in hue and lightness. Converting between them keeps a brand colour identical everywhere it appears.

  • HEX is the everyday web format — shortest and supported everywhere in CSS.
  • HSL is best for building a palette: keep the hue, then vary lightness for shades and tints.
  • Copy brand colours from the original source file rather than eyeballing a screenshot — screens shift colours.

Frequently asked questions

When should I use HEX, RGB or HSL?

HEX is the classic choice for CSS and design tools. RGB (and rgba) is handy when you need transparency. HSL is the most human-friendly for code: you can lighten, darken or shift a color predictably by changing one number.

What is the difference between HSL and HSV?

Both describe a color by hue and saturation, but they measure brightness differently. In HSL, lightness runs from black (0%) through the pure color (50%) to white (100%); in HSV, value runs from black (0%) to the pure color (100%). Design tools like Figma usually use HSV/HSB; CSS uses HSL.

How are the shades and tints generated?

Shades mix the base color with black (40% and 20% darker steps) and tints mix it with white (20% and 40% lighter steps), with the untouched base color in the middle — a standard, reliable way to build a small palette.

Why did my HEX code show an error?

HEX codes must be 3 or 6 characters of 0–9 and A–F, with an optional leading #. Codes like #12345 (five digits) or letters beyond F are not valid colors.
