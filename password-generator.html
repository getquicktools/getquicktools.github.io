Password Generator

Create a strong, random password in one click. Choose the length and character types, check the strength meter, and copy it straight to your clipboard.

🔒 Private by design: passwords are generated locally in your browser using crypto-grade randomness — they are never uploaded, logged or stored.

How to use

  1. Set the length with the slider — 16 or more characters is recommended for important accounts.
  2. Tick the character types you want (some sites disallow symbols — untick them there).
  3. Click Generate new password until you're happy, checking the strength meter.
  4. Click Copy to clipboard and paste it into a password manager — never reuse it elsewhere.

Frequently asked questions

How random are these passwords?

They are generated with crypto.getRandomValues, the cryptographic random number generator built into your browser — the same source of randomness used by security software. Nothing predictable like the current time is used.

Can anyone see or recover a password I generated?

No. Generation happens entirely on your device and passwords are not sent anywhere or saved. Once you close the tab, a password that you didn't copy or store is gone forever.

How long should my password be?

Length beats complexity. A 16-character password using all character types would take centuries to crack by brute force; 20+ is even better for banking and email accounts.

Should I use a different password for every site?

Yes. Unique passwords mean one site's data breach can't unlock your other accounts. Use a reputable password manager to remember them all.
